# EDUC-Week-11-Assignment
data analysis by using panda and metplotlib in Jupyter notebook

For this assignment, I analyzed the Data Science Job Salaries dataset using Python (pandas and matplotlib) in a Jupyter Notebook.
The goal was to explore what skills and locations are associated with higher salaries in the data science field.
I cleaned the dataset, calculated average salaries by job title and country, and visualized the results with bar charts.
The findings show that technical roles such as Machine Learning Engineer and Data Engineer offer the highest salaries, and that salaries are generally highest in the United States, Switzerland, and Australia.
